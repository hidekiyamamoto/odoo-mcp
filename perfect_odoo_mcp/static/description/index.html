Perfect Odoo MCP

Expose Odoo as a native MCP server with Odoo login, user ACLs, OAuth discovery, optional SQL, custom tools, and controlled editing for selected installed modules.

Odoo OAuth ACL-aware tools Context bootstrap Optional SQL Custom tools Installed module editing

Local Odoo addon installation required

Perfect Odoo MCP is not compatible with Odoo's Apps > Import Module upload flow. It defines Python controllers, models, OAuth routes, and MCP endpoints, so it must be installed as a normal local addon from an Odoo addons path and loaded by the Odoo server.

Install On Debian-Style Odoo

Run the installer from the Odoo host or container. It detects Odoo, chooses the matching branch, deploys the addon, restarts Odoo when possible, and refreshes the app list when a database is provided.

curl -fsSL https://raw.githubusercontent.com/hidekiyamamoto/odoo-mcp/main/install-perfect-odoo-mcp.sh | bash -s -- --database YOUR_DATABASE

Built Inside Odoo

Perfect Odoo MCP is an Odoo app, not an external adapter. MCP calls enter Odoo, authenticate through Odoo, and execute with the authorized user's environment.

Odoo login and ACLs

Users authorize through Odoo OAuth. Record access follows Odoo security rules instead of a shared integration user.

Operational discovery

Inventory installed modules, inspect Python addon code, and store instance-specific AI context for future sessions.

Automatic context bootstrap

When context is empty, the server gives the AI a startup protocol for inspecting the database and saving durable guidance.

Optional SQL

Expose direct PostgreSQL access only when enabled, with readonly mode and statement guards for safer diagnostics.

Context That Initializes Itself

The first context request is not a blank answer. If no durable context exists yet, Perfect Odoo MCP tells the consuming AI exactly how to bootstrap itself for this database before doing real work.

Read

Call get-ai-context and receive the bootstrap protocol.

Inspect

Run install_info and identify custom or unusual modules.

Verify

Use odoo_python_lookup to inspect relevant addon code.

Persist

Write the final operating context with set-ai-context.

Custom Tools And Module Editing

Perfect Odoo MCP can help develop new capabilities safely. Draft custom tools live outside the addon directory. Module editing is separately gated and works only for explicitly selected installed Odoo modules.

Custom MCP tools

Write draft Python tools with EXPOSED = False, test them with call-custom, then publish only after review.

Editable module list

Settings provide a real editable list. Each row selects an installed module; the addons directory and module folder are detected automatically.

Focused file editing

The module editor can list files, read, write, and delete files inside the selected module folder only.

Readonly paths

The settings list shows the detected addons directory and module folder as readonly values so configuration stays simple.

Use With AI Clients

After installation, copy the HTTPS endpoint from Settings and connect it from an MCP-capable client. OAuth metadata is exposed for clients that support discovery and dynamic registration.

ChatGPT

Create a custom MCP connector, use the Perfect Odoo MCP endpoint, choose OAuth discovery, authorize in Odoo, then refresh actions when tools change.

Gemini CLI

Add the remote HTTP MCP server with gemini mcp add --transport http perfect-odoo-mcp https://your-domain/perfect_odoo_mcp/mcp.

First run

Ask the client to call get-ai-context. If context is empty, use medium or high reasoning and complete the bootstrap before business work.

Tool Surface

search and fetch: broad connector-style discovery.

odoo_search: precise model/domain ID lookup.

odoo_search_read: precise model/domain reads with selected fields.

install_info: Odoo version, domain, company, and module inventory.

odoo_python_lookup: read-only Python addon code search/read.

get-ai-context and set-ai-context: durable instance guidance.

odoo_sql: optional direct PostgreSQL access.

odoo_module_edit: optional installed module file editor.

Perfect Odoo MCP is designed as a foundation for Odoo-native MCP workflows: inspect safely, understand the database, and then act through controlled tools.
